# Project instructions

## Writing style

**Never use em dashes (—) in any communication.** This applies everywhere, without
exception: chat replies, commit messages, code comments, documentation, drafted
emails, support tickets, PR descriptions, and any text written on the owner's behalf.

En dashes (–) used as a stand-in for an em dash are also out.

Use one of these instead:

- a comma, when the clause is a simple aside
- a colon, when what follows explains or expands on what came before
- parentheses, for a genuine aside
- a full stop and a new sentence, when the thought is separable

A hyphen (-) in a compound word (`force-with-lease`, `bot-evasion`) is fine. So is a
minus sign, and a hyphen used as a list bullet. The rule is about the long dash used
as punctuation between clauses.
